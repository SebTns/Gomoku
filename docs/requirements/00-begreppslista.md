# Begräppslista
Lista med termer och deras betydelser för att underlätta förståelsen. Dessa definitioner tar företräde vid konflikt.

## Domäntermer

| Term | Definition |
|-----|-----------|
| Gomoku | Strategispelet för två spelare som den här applikationen är baserad på. Även känt som Fem i rad.|
| Svart (Black) | Stenfärgen som tilldelas spelaren som rör sig först. Tilldelas slumpmässigt eller efter preferens när spelet börjar.|
| Spelbord (Board) | Den rektangulära spelplanen är ett rutnät där spelet spelas. Standard är 15x15 med en äldre 19x19-version. |
| Vit | Stenfärgen som tilldelas spelaren som flyttar tvåa. |
| Svårighetsgrad | AI-motståndarens styrkenivå: lätt, medel eller svår. |
|  fem i rad | Exakt fem på varandra följande stenar av samma färg i en rak linje (horisontellt, vertikalt eller diagonalt). Det enda vinstvillkoret i standard Gomoku. |

| Oavgjord match | Ett spelresultat där spelplanen är helt fylld och ingen har fem i rad. |
| Utmaning | En inbjudan från en registrerad spelare till en annan att starta ett flerspelarspel.|
